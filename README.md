# Notyga — showcase website

Source of [www.notyga.com](https://www.notyga.com). Plain HTML, CSS and a
little JavaScript: no framework, no database, nothing running on the server.

```
.
├── index.html, fr/index.html          Homepages, EN and FR      ─┐ generated by
├── legal/, fr/mentions-legales/       Legal notice and privacy   │ build_pages.py,
├── 404.html, robots.txt, sitemap.xml                            ─┘ committed
├── assets/                            CSS, JS, fonts, images
└── tools/                             Scripts, not published
    ├── build_pages.py                 All the text, and the page generator
    ├── deploy.py                      Build and publish over SSH
    ├── build_share.py                 Export a page as standalone HTML + PDF
    └── build_assets.py                Regenerate logos/images (needs Pillow)
```

Only Python 3 is needed (standard library), plus SSH to publish.

## Changing the site

1. Edit the text in the `COPY` dictionary of `tools/build_pages.py`. The pages
   are generated from it so English and French stay in step; avoid editing
   the HTML by hand, the next build would overwrite it.
2. Regenerate: `python tools/build_pages.py`
3. Preview: `python -m http.server 8000`, then open http://localhost:8000
   (open `/404.html` directly to see the error page).
4. Commit, then publish.

## Publishing

```bash
python tools/deploy.py --dry-run   # build and list what would be sent
python tools/deploy.py             # build and publish
```

The script builds the site into a temporary folder, sends it to the web
server over SSH as one archive, and replaces the content of the served folder
with it. Only the public files go out: never `tools/`, `.git/` or this README.

The destination is read from a git-ignored `deploy.local.json` at the
repository root, so server details stay out of the repository:

```json
{"host": "<ssh host>", "dir": "<folder served by the web server>"}
```

## Legal notice and privacy policy

Generated from the top of `tools/build_pages.py`:

- `LEGAL`: company details. A field set to `None` appears on the page as a
  highlighted *"À compléter"*, and the build warns about it.
- `HOST`: who hosts the site, one of `HOSTS`. The page must always name the
  actual host, and its `log_days` must match how long the server keeps its
  access logs.
- `LEGAL_UPDATED`: the date shown on the page, to change with the content.

To send the page for review, `python tools/build_share.py` writes a standalone
HTML file and a PDF into `_share/` (not committed). `--compare ovh_web ovh_vps`
shows the host-dependent passages side by side as options A/B.

## Branches

- **`notyga.com`**: the live site, www.notyga.com.
- **`main`**: the former address notyga.fr, still published by GitHub Pages
  (`.github/workflows/pages.yml`, `CNAME`) until it redirects to
  www.notyga.com. Not to be merged with `notyga.com` before then, or Pages
  would publish a legal page naming the wrong host.

## Design notes

- **Text.** Everything carried over from the old site is reproduced verbatim
  and marked `# verbatim` in `COPY`. No client names, figures or testimonials
  were invented.
- **Palette.** One green family sampled from the logo (`#006401`) plus warm
  neutrals; tokens at the top of `styles.css`.
- **Logo.** `assets/img/logo.svg` and `logo-white.svg` are the vector paths of
  `Logo Notyga V2.pdf`, always used whole. `logo-full.png` is only for share
  previews.
- **Fonts.** Inter and JetBrains Mono, self-hosted in `assets/fonts/` (SIL
  OFL). Nothing is loaded from third parties, so no cookie or consent banner is
  needed.
- **Motion and accessibility.** Animations are progressive enhancement and off
  under `prefers-reduced-motion`. Skip link, landmarks, visible focus, alt
  text, WCAG AA contrast throughout.
